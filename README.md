# iClima-softwares
Code for the analysis of the paper 'iClima: a ratiometric genetically encoded sensor for optical imaging of fast GABAergic chloride currents in vitro and in vivo'

The environment is divided into subfolders depending on the analysis:
1) iClima Calibrations
2) iClima in vitro
3) iClima in vivo
4) iClima and GCaMP6f
5) Visual Stimulation

Please note that a substantial part of the code for the analysis was already published in another Github repository as stated in the corresponded folders.
